# 完整报告导出

一次性子任务完成后，在其「实例配置」点击「导出完整报告」。浏览器下载 `subagentbook-<sessionId>.report.json`，包含完整的 `text` 和来源字段；客户端校验正文SHA与长度后才触发下载。导出直接读取宿主持久化结果，不让模型重新抄写，不删除导语、代码围栏或纠正原文错字。

`sha256` 是 `text` 的UTF-8 SHA256，`totalChars` 是UTF-16代码单元数（与分页接口一致），`totalBytes` 是UTF-8字节数。哈希不是整个JSON文件的哈希；JSON编码中的转义也不是正文修改。来源字段包括实例/直接父级ID、保存的角色与模型路由、深度、权限模式及配置版本。缺失/损坏/归属不一致会拒绝导出，不用最新消息替代。

这是已认证用户的只读Remote，不是新增模型工具。模型的 `subagentbook_result` 仍只允许原来的直接父级分页读取自己的one-shot报告。用户导出允许读取已经结束、Agent不再驻留的历史实例，不必重新运行或恢复它。根角色和持续会话不显示这个按钮：持续会话多轮输出不等于一个已冻结的一次性交付，当前不支持其报告导出。

## 本地原文与清单

在Subagentbook源码仓库运行：

```bash
npm run report:export -- '/absolute/DSH_HOME' 'one-shot-session-id' '/absolute/evidence/r04-chief'
```

工具只读取该DSH_HOME下匹配实例/父级的现有报告，并在新目录生成：

- `report.md`：完整最终交付原文，不添加标题、归属说明、尾部换行或换行转换。
- `manifest.json`：正文SHA、长度、实例与来源字段，不重复正文。

目标目录必须不存在；旧轮次不能被覆盖。命令失败不会回退成另一个实例或最新预设。临时的模型推理、Persona、请求配置、环境和凭据不在导出字段中。CLI运行者需要已有的本地文件访问权限；没有给Agent增加任意宿主文件访问或向任意目录写文件的工具。

## 轮次与验收

以实例ID/父级ID标识每次one-shot交付；由外部轮次索引将 `r04 / chief` 等人工标签绑定到这些ID和报告SHA。不要从正文里的“我是主审”猜真实角色或从标题猜轮次。一个最终交付可能包含多份报告，其完整原文仍作为一个报告保存；拆分、转述或修订另存，不冒充原件。

来源字段来自当时保存的实例记录，正文来自已有不可变报告。SHA与存储校验用于发现不一致，不是作者身份签名，也不证明模型声称的测试或审查结论真实。旧版one-shot实例元数据没有新增签名；本功能不会给历史来源补造更强保证。C/W/S统计与最终版本检查点仍需独立对账，不能因导出成功而放行。
